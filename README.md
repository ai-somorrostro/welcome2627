# Configuración de GitHub y primera rama

1. Crear una cuenta de GitHub con vuestro email del centro
   - Nombre de la cuenta "nombre.apellido" (ej: mikel.diez)

2. Configurar una clave SSH (en vuestro entorno), además es el momento de configurar localmente el usuario y el email (diapositiva 5)

3. Unirse a la clase (en GitHub) vía invitación (este paso se hace manual)

4. Clonar el repo de welcome

5. Crear y pushear una rama nombre.apellido (ej: mikel.diez)
   - Clonar `git@github.com:ai-somorrostro/welcome2627.git`
   - Crear y moverse a la rama
   - Crear fichero nombre.apellido.txt (ejemplo mikel.diez.txt)
   - Escribir dentro del fichero nombre.apellido.txt -> nombre.apellido (ejemplo mikel.diez)
   - Commitear con el mensaje nombre.apellido
   - Pushear la rama a GitHub
